Brazo Robótico - Tinkercad

Descripción
Sistema de brazo robótico articulado de 4 grados de libertad desarrollado en Tinkercad Circuits, diseñado para demostrar principios fundamentales de robótica, mecatrónica y control automático. El proyecto simula un brazo manipulador industrial en miniatura capaz de ejecutar movimientos precisos mediante control por comandos seriales

Características
- Control de 4 servomotores
- Interfaz serial para comandos
- Simulación en Tinkercad

Metodos para uso
Arduino
Ve a: https://www.arduino.cc/en/software
Descarga la versión para tu sistema operativo
Instala siguiendo el asistente
y Abre el archivo .ino cargado en este repositorio

Tinkercad
Copia todo el código del .ino
Ve a Tinkercad → Tu circuito → Código
Pega el código y haz click en "Start Simulation"

Instalación
1. Abre el circuito en Tinkercad
2. Carga el código `brazo-robotico.ino`
3. Configura el monitor serial
