# Brazo robotico 3D - Equipo 10
Brazo Robótico - Tinkercad

##  Descripción
Proyecto de brazo robótico controlado por Arduino desarrollado en Tinkercad.

##  Características
- Control de 4 servomotores
- Interfaz serial para comandos
- Simulación en Tinkercad

##  Instalación
1. Abre el circuito en Tinkercad
2. Carga el código `brazo-robotico.ino`
3. Configura el monitor serial

##  Uso
```bash
# Comandos disponibles
MOVER 90 45 180 0
HOME
RESET
